# Methods of Synthesis of Virtual Reality — Control Task

## AR registration template

This branch implements the **Control Task (AR registration template)** for variant **14**.

The project uses:

- a custom registration marker `assets/pattern-14.patt`;
- AR.js and A-Frame for marker tracking;
- the same DROP surface from PA#1/PA#2;
- `marker.html` for displaying the marker on a laptop screen;
- `index.html` for the smartphone AR view.
