PA#2 — Tangible interface: Android magnetometer controls the surface

This version keeps PA#1 capabilities and adds a smartphone as a tangible controller. Android Sensor Server streams hardware magnetometer data through WebSocket. Because variant 14 uses only one magnetometer vector, the DROP surface receives compass-like yaw rotation around the vertical axis. Keep the phone as flat as possible for a stable result.

Android Sensor Server

Not connected. Start Sensor Server on Android, check that phone and PC are in the same Wi‑Fi network, then enter the WebSocket URL and press Connect.
